# Legacy MATLAB Tools

This directory preserves the original contents of this repository from its earlier life as a collection of MATLAB utilities for psychology and behavioral-research workflows.

The files are kept primarily for continuity and historical usefulness. They have not been systematically modernized as part of the Field Notes restructuring, so treat individual utilities according to their local documentation and test status.

The original repository README is preserved as [`README-original.md`](README-original.md).
